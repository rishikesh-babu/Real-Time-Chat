# CHATLY - Real-Time Chat Application

A premium, modern real-time chat application built with React, Node.js, and Socket.io. Features a sleek glassmorphism UI, real-time messaging, and responsive design.

## ✨ Features

- **Real-Time Messaging**: Instant message delivery using WebSockets.
- **Modern UI/UX**: Premium glassmorphism design with smooth animations.
- **Responsive Layout**: Seamless experience across mobile and desktop.
- **User Search**: Easily find and start conversations with other users.
- **Unread Indicators**: Visual cues for missed messages.
- **Dynamic Input**: Auto-growing message area with support for multiline text.

## 🚀 Tech Stack

- **Frontend**: React, Tailwind CSS, DaisyUI, Redux Toolkit, Lucide React.
- **Backend**: Node.js, Express, Socket.io.
- **State Management**: Redux for user data and application state.

## 🛠️ Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/Real-Time-Chat.git
   cd Real-Time-Chat
   ```

2. **Install Server Dependencies**:
   ```bash
   cd server
   npm install
   ```

3. **Install Client Dependencies**:
   ```bash
   cd ../client
   npm install
   ```

### Running the Application

1. **Start the Backend Server**:
   ```bash
   cd server
   npm start
   ```
   *The server will run on port 5000 by default.*

2. **Start the Frontend Client**:
   ```bash
   cd client
   npm run dev
   ```
   *The client will be accessible at http://localhost:5173.*
